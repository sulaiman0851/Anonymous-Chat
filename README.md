## ✨ Features

- 📸 Acces webcam.
- 📩 Send anonymous messages.
- 📊 Real-time message saved in local directory.
- 🎨 Minimalist UI with a smooth experience.
- 🌐 Accessible locally & online via Ngrok.

## 🚀 Getting Started

Follow these steps to set up the project on your local machine.

### 1️⃣ Prerequisites
Make sure you have the following installed:
- PHP (for running a local server)
- Ngrok for online access (optional)

### 2️⃣ Clone this repository
```sh
git clone https://github.com/sulaiman0851/Anonymous-Chat.git
```

### 3️⃣ Run Locally
To start the project locally, open a terminal and navigate to the project folder, then run:

```sh
php -S 0.0.0.0:3000
```

This will start a local server at `http://0.0.0.0:3000`. You can open it in your browser.

### 4️⃣ Expose Online with Ngrok
If you want to access your project online, use Ngrok:

```sh
ngrok http 3000
```

After running this command, Ngrok will generate a public URL that you can share!
